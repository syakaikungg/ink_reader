# 開発の基本方針

2026-10-26 に決めた草案。原文と議論は [Claude Doc](https://claude.ai/artifact/1bk73Z2DoGhCt7DoP6Ftcp) にあり、まだ確定ではない。

## 目指す姿

GoodNotes の機能を基本的にすべて備えたうえで、AI と一緒に勉強できる手書きノートアプリにする。GoodNotes の上位互換を目指す。

- **何でも開ける**：Markdown のようなテキストも、PDF のようなバイナリも、同じ使い心地で開いて書き込める。
- **AI にそのまま渡せる**：本文と手書きを、AI が文脈ごと読める形で持つ。
- **滑らかさは譲らない**：書く・開く・めくる・拡大するのどれでも、待たされたりカクついたりしない。

その先の目標は、**自分の理解度を知っている AI の家庭教師**。一緒に勉強しながら、どこがまだ分かっていないかを AI が分析して教えてくれる。そのために、今のうちから次のことを守る。

- 学びの跡を捨てずに残す。どこを読み、どこに何を書き、何を質問して AI がどう答えたかを、本文の場所と結びつけて記録する。
- 理解度は、AI も人も読み書きできる md ファイルで持つ。
- 質問は同じ場所（いつものセッション）に集める。

## 原則（上ほど優先。ぶつかったら番号の小さいほうを取る）

1. **軽さと滑らかさが最優先**。機能を足して重くなるなら、その機能は入れない。速さは数値で測って守る（下の表）。
2. **AI がそのまま読める形で保存する**。手書きは画像にせず、線のデータとして持つ。どこに書いたか（アンカー）も一緒に持つ。形式は公開した普通のファイル（md・JSON・PDF）にし、書き込みは元のファイルを壊さない別ファイルに置く。
3. **テキストと PDF を同じように扱う**。md は段落、PDF はページと座標に書き込みを結びつける。それ以外の道具は共通にする。
4. **GoodNotes の上位互換**。機能はよく使うものから順に入れる。
5. **オフライン第一で、データは自分のもの**。書いた瞬間に端末へ保存し、同期は裏で行う。
6. **AI はサブスクの範囲で使う**。API の従量課金を前提にしない。

## 軽さの基準（草案）

| 場面 | 目標 |
| --- | --- |
| ペンで書く | 線がペン先に遅れて見えない。描画は毎フレーム（120Hz の iPad なら 120fps） |
| スクロール・拡大 | 書き込みが多いページでもコマ落ちしない |
| ファイルを開く（一度開いたもの） | 最初の画面が 0.3 秒以内に出る |
| 大きな PDF（500 ページ級） | 開く時間がページ数で増えない（見えているページだけ描く） |
| 保存・同期 | 書いている最中に止まらない |
| アプリの起動 | 通信なしでも 1 秒以内に書ける状態になる |
