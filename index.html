Pencilで書いてみてください

Apple Pencilで書き込み、指でスクロール、2本指のピンチで拡大・縮小（拡大率の数字を押すと一覧からも選べます）。書いた線の上をペンでぐちゃぐちゃっと塗ると消えます。線の終わりでペンを止めて押さえると、直線・円・三角・四角に直ります（離さずに動かすと向きや大きさが変わり、あとから丸いつまみで形を直せます。マーカーも止めると直線になります）。「ペン」をもう一度押すと、色と太さを選べます。消しゴムをもう一度押すと、線ごと消すか、なぞった所だけ消すかと、丸の大きさを選べます（書き込みを全部消すのもここから）。左上の矢印で、戻す・進むができます。「投げ縄」で囲むと、ドラッグで移動、「色・太さ」で変更、削除ができ（ペンのまま丸で囲み、その線をペンで長押ししても選べます）、「Claudeに聞く」でその箇所について質問できます（Claude の答えは、段落の右の「Q」から開けます）。本と書き込みはiPadに保存されるので、通信なしでも開けます。「本」から md ファイルや PDF を開けます（PDF は右下のページ番号を押すと、そのページへ飛べます。そこの「書き出す」で、ページを選んで書き込みごと PDF にできます）。設定で Google ドライブにつなぐと、書き込みは通信できるときにドライブへ送られ、Claude が読めるようになります。

読みたい md ファイルか PDF を選んでください（md をいくつか選ぶと、1ファイルが1章になります）。本と書き込みはこのiPadの中に保存されます。

GitHub のリポジトリにある本を読みたいときは「設定」からトークンを入れてください。

設定

Google ドライブ

書き込み・画像・Claude の答えを、ドライブの「Ink Reader」フォルダに置きます。Claude のドライブ連携で、本と手書きを読んで答えられるようになります（GitHub には本文だけを置きます）。

GitHub

sakai_study の本文を読める GitHub のトークン（fine-grained、Contents: Read-only で足ります）を入れてください。トークンはこのiPadの中だけに保存されます。
