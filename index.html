Pencilで書いてみてください

Apple Pencilで書き込み、指でスクロール、2本指のピンチで拡大・縮小（拡大率の数字を押すと画面幅に戻ります）。書いた線の上をペンでぐちゃぐちゃっと塗ると消えます。「投げ縄」で囲むと、ドラッグで移動、色・太さボタンで変更、削除ができ、「Claudeに聞く」でその箇所について質問できます（sakai_study で聞いた答えは、段落の右の「Q」から開けます）。本と書き込みはiPadに保存されるので、通信なしでも開けます。「本」から md ファイルを開けます。GitHub の本は、書き込みが通信できるときに GitHub へ送られます。

読みたい md ファイルを選んでください（いくつか選ぶと、1ファイルが1章になります）。本と書き込みはこのiPadの中に保存されます。

GitHub のリポジトリにある本と同期したいときは「設定」からトークンを入れてください。

設定

sakai_study の中身を読み書きできる GitHub のトークン（fine-grained、Contents: Read and write）を入れてください。トークンはこのiPadの中だけに保存されます。
